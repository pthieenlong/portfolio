## Overview

eSmiles is a SaaS platform for dental clinics, built with a **Next.js** frontend and a **NestJS** backend.

The source code is private, so this page only gives a high-level description.

## Stack

- **Frontend:** Next.js (App Router), React, TypeScript, TailwindCSS
- **Backend:** NestJS, TypeScript
- **Database:** PostgreSQL
