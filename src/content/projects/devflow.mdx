## Overview

DevFlow is a developer-first task management tool that integrates directly with GitHub. It automatically creates tasks from issues, tracks PRs, and uses AI to estimate effort and suggest assignments.

## Problem

Most project management tools aren't built with developers in mind. Switching between GitHub, Jira, and Slack creates context-switching overhead and leads to tasks falling through the cracks.

## Solution

DevFlow pulls GitHub issues and PRs directly into a unified board, syncing in real-time. An AI assistant analyzes past sprint data to help with estimation and workload balancing.

## Key Features

- **GitHub Sync** — two-way sync with GitHub Issues and Pull Requests
- **Real-time board** — live updates via WebSocket, no refresh needed
- **AI Estimation** — GPT-powered effort estimation based on task description
- **Sprint Analytics** — velocity charts, burndown graphs, and team insights
- **Slack Integration** — daily digests and blocker alerts

## Technical Highlights

- Built with **Next.js 14 App Router** and **React Server Components**
- **Prisma ORM** with PostgreSQL for type-safe database access
- **Socket.io** for real-time collaboration features
- **OpenAI API** integration for AI-powered features
- Deployed on **Vercel** with edge functions for low-latency API routes
- End-to-end tests with **Playwright**

## Outcome

Used by 3 internal teams during beta. Reduced average sprint planning time by 35% and improved task completion rate by 22%.
