## Overview

ShopWave is a headless storefront built on top of the Shopify Storefront API. It replaces the default Shopify theme with a blazing-fast, fully custom React frontend while keeping all backend commerce logic in Shopify.

## Problem

Default Shopify themes are slow and hard to customize deeply. Brands that care about performance and bespoke UX are limited by Liquid templates and theme architecture.

## Solution

Decouple the frontend entirely using Shopify's Storefront GraphQL API. Build the UI with Next.js for SSR/ISR support, delivering store pages with optimal Core Web Vitals.

## Key Features

- **Product catalog** — filterable, searchable with instant results
- **Cart & Checkout** — persistent cart with Shopify's hosted checkout
- **Wishlist** — client-side wishlist with localStorage persistence
- **Product reviews** — integrated with Judge.me API
- **SEO optimized** — dynamic OG images, structured data, sitemap

## Technical Highlights

- **Next.js ISR** — product pages regenerated on demand, no stale data
- **Shopify Storefront API** with typed GraphQL queries via `graphql-codegen`
- **TailwindCSS** with a custom design token system
- **Framer Motion** page transitions and micro-interactions
- Lighthouse score: **98 Performance / 100 Accessibility / 100 SEO**

## Outcome

Client's conversion rate improved by 18% after launch. Page load time dropped from 4.2s to 0.8s on mobile.
