## Overview

GlassUI is an open-source React component library built around the glassmorphism aesthetic. It ships with full TypeScript support, WCAG 2.1 AA accessibility compliance, and a Storybook documentation site.

## Motivation

I kept rebuilding the same glass-effect components across projects. GlassUI extracts those into a reusable, well-tested library so the community can benefit too.

## Components

| Category | Components |
|----------|------------|
| Layout | Card, Glass, Container, Divider |
| Forms | Input, Select, Checkbox, Radio, Switch |
| Feedback | Toast, Alert, Badge, Progress |
| Navigation | Tabs, Breadcrumb, Pagination |
| Overlay | Modal, Drawer, Popover, Tooltip |

## Technical Highlights

- **Rollup** build pipeline producing ESM + CJS bundles
- **CSS custom properties** for themeable design tokens
- **Radix UI primitives** for accessibility underpinnings
- **Vitest + Testing Library** — 85%+ test coverage
- **Storybook 7** with auto-generated docs from TypeScript types
- **Semantic release** for automated versioning and changelogs

## Outcome

Published on npm. 200+ GitHub stars, 40+ weekly downloads within 3 months of release.
